\begin{frame}{}
\frametitle{O que é lógica?}
\pause
\begin{itemize}
    \item Lógica (como uma ciência, uma área do conhecimento) é o estudo de um tipo muito específico de pensamento.\pause
    \item Pensamento racional? Analítico? Dedutivo? Formal? Mecânico? \pause
    \item A lógica matemática 'captura' este tipo de pensamento em definições matemáticas (sistemas axiomáticos e dedutivos, linguagens formais, etc). \pause
    \item O cálculo proposicional e a lógica de primeira ordem são os sistemas lógico-matemáticos mais comuns e difundidos, mas também tem muitos outros (lógicas não clássicas, lógicas modais, lógicas paraconsistentes, etc). \pause
    \item Por essas coisas serem objetos matemáticos, podemos fazer matemática sobre elas!
\end{itemize}
\end{frame}

\begin{frame}{}
\frametitle{O Cálculo Proposicional}
\pause
\begin{itemize}
\item O cálculo proposicional é uma linguagem formal cujo alfabeto é composto de enumeráveis símbolos $p_1,p_2, p_3, \dots$ e os símbolos conectores $\wedge, \vee, \lnot, \rightarrow$ \pause
\item As 'palavras' formadas por este alfabeto de forma 'correta' são chamadas de fórmulas, e são coisas do tipo $p_2 \wedge (\lnot p_1 \rightarrow (p_3 \vee p_5$)) \pause
\item Usar como uma linguagem já é útil pra matemática! \pause
\item Mas fazemos mais: definimos algumas fórmulas como especiais (por exemplo, as fórmulas $p \rightarrow p$, $p \vee \lnot p$ e $\lnot(p \wedge \lnot p)$ parecem representar 'verdades'), que vão ser as chamadas 'tautologias'. \pause
\item Também teremos um sistema dedutivo onde definimos quando que um conjunto $T$ de fórmulas deduz uma outra fórmula $\alpha$. (por exemplo, a partir das fórmulas $p \rightarrow q$ e $p$, podemos deduzir $q$) \pause
\item De novo, estas são práticas comuns no fazer matemático. 
\end{itemize}
\end{frame}

\begin{frame}{}
\frametitle{A Lógica de Primeira Ordem}
\pause
\begin{itemize}
\item A lógica de primeira ordem é uma extensão do cálculo proposicional onde agora temos também símbolos que irão representar variáveis, constantes, funções, relações e quantificadores. \pause
\item As fórmulas vão ser coisa do tipo $\exists x ((f(x,c) = d) \vee (R(x) \rightarrow x = d))$ \pause
\item Agora nossa linguagem consegue falar de basicamente qualquer tópico matemático. \pause
\item Também vamos ter aqui as fórmulas especiais (as que são sempre verdade), e um sistema dedutivo (que é basicamente Modus Ponens também). \pause
\item A coisa começa a ficar realmente legal quando colocamos semântica - vamos falar disso mais pro final.
\end{itemize}
\end{frame}

\begin{frame}{}
\frametitle{O que é álgebra?}
\pause
\begin{itemize}
    \item Álgebra é o estudo matemático de conjuntos com operações. \pause
    \item Operações: somar um número com outro número, compor uma função com outra função, aplicar uma simetria após a outra... \pause 
    \item Estudamos as 'propriedades gerais' que um conjunto com uma (ou mais que uma) operação deve satisfazer (geralmente, sempre supondo que ele satisfaça certas propriedades, colocadas em equações).\pause
    \item Por exemplo: anéis e espaços vetoriais. \pause
    \item Existe algo que chama 'álgebra universal' onde você tenta fazer todas as álgebras ao mesmo tempo.
\end{itemize}
\end{frame}

\begin{frame}{}
\frametitle{A álgebra da lógica}
Na lógica temos operações no conjunto de fórmulas: $\vee, \wedge, \exists$... Qual é a estrutura algébrica aqui?
\end{frame}

\begin{frame}{}
\frametitle{Algebrização de Lindenbaum-Tarski}
\pause
\begin{itemize}
    \item Dados duas fórmulas $\alpha, \beta$ do cálculo proposicional, diga que $\alpha$ é equivalente a $\beta$ quando $(\alpha \rightarrow \beta) \wedge (\beta \rightarrow \beta)$ é uma tautologia. \pause
    \item O conjunto de todas as fórmulas do cálculo proposicional, quocientado por essa relação de equivalência, forma uma álgebra com as operações $\vee, \wedge, \lnot$. \pause
    \item Agora $\vee$ e $\wedge$ são comutativos, e satisfazem várias outras equações. \pause
    \item Podemos fazer o mesmo processo com a lógica de primeira ordem. E com outras lógicas também! Estas são as álgebras de Lindenbaum-Tarski.
\end{itemize}

\end{frame}

\begin{frame}{}
\frametitle{Álgebra de Boole}
\pause
Uma álgebra de Boole $\mathcal{B}$ é um conjunto com duas operações binárias $\vee$ e $\wedge$, uma operação unária $\lnot$ e dois elementos $0,1 \in \mathcal{B}$ onde valem: \pause
\begin{itemize}
    \item associatividade: $(\alpha \vee \beta) \vee \gamma = \alpha \vee (\beta \vee \gamma)$ e $(\alpha \wedge \beta) \wedge \gamma = \alpha \wedge (\beta \wedge \gamma)$ \pause
    \item comutatividade $\alpha \vee \beta = \beta \vee \alpha$ e $\alpha \wedge \beta = \beta \wedge \alpha$ \pause
    \item distributividade $\alpha \vee (\beta \wedge \gamma) = (\alpha \vee \beta) \wedge (\alpha \vee \gamma)$ e $\alpha \wedge (\beta \vee \gamma) = (\alpha \wedge \beta) \vee (\alpha \wedge \gamma)$ \pause
    \item identidade $\alpha \vee 0 = \alpha$ e $\alpha \wedge 1 = \alpha$ \pause
    \item complemento $\alpha \vee \lnot \alpha = 1$ e $\alpha \wedge \lnot \alpha = 0$ \pause
    \item absorção $\alpha \vee (\alpha \wedge \beta) = \alpha$ e $\alpha \wedge (\alpha \vee \beta) = \alpha$ \pause
\end{itemize}
A algebrização de Lindenbaum-Tarski do cálculo proposicional e da lógica de primeira ordem dão origens a álgebras de Boole! \pause (e meio que todas vem daqui). \pause
Conjuntos de conjuntos com união, interseção e complementar também são álgebras de Boole. \pause (e também todas são isomorfas a uma desse tipo).
\end{frame}

\begin{frame}{}
\frametitle{Álgebra de Halmos}
E os quantificadores?\\ \pause

Uma função $\exists: \mathcal{B} \rightarrow \mathcal{B}$ de uma álgebra de Boole $\mathcal{B}$ nela mesma é dita um quantificador se satisfaz \pause
\begin{itemize}
\item $\exists 0 = 0 $ \pause
\item $\alpha \leq \exists \alpha$ (isto significa que $\alpha \wedge \exists \alpha = \alpha)$ \pause
\item $\exists (\alpha \vee \beta) = (\exists \alpha) \vee (\exists \beta)$ \pause
\item $\exists \exists \alpha = \exists \alpha$ \pause
\item $\exists \lnot (\exists \alpha) = \lnot(\exists \alpha)$ \pause
\end{itemize}

Uma álgebra de Boole monádica é uma álgebra de Boole com apenas um quantificador. \\ \pause

Uma álgebra de Halmos, ou uma álgebra poliádica, é uma álgebra de Boole com vários quantificadores e 'uma estrutura que descreve como estes quantificadores interagem' (substituições de variáveis). \pause

A álgebra de Halmos captura a estrutura algébrica da lógica de primeira ordem.
\end{frame}

\begin{frame}{}
\frametitle{Semântica - completude do cálculo proposicional}
\pause

\begin{itemize}
\item Também conseguimos fazer os resultados semânticos (a parte mais legal!) dentro desse framework. \pause

\item Em cálculo proposicional, uma valoração $u$ é uma associação, pra cada fórmula, pra $0$ ou $1$ que satisfaz 'o que esperamos' do ou, e, negação. \pause

\item Podemos descrever isso algebricamente como um homomorfismo $u: \mathcal{B} \rightarrow \{0,1\}$ da álgebra de Boole do cálculo proposicional para a álgebra de Boole $\{0,1\}$. \pause

\item O famoso 'teorema da completude do cálculo proposicional' diz que se um conjunto de fórmulas $T$ não consegue provar a contradição ($\alpha \wedge \lnot \alpha)$, então existe uma valoração que valora todos as fórmulas de $T$ como $1$. \pause

\item Isso é equivalente ao 'lema do ultrafiltro' que diz que pra todo subconjunto $T \subset \mathcal{B}$ de uma álgebra de Boole que satisfaz PIF (que pra qualquer conjunto finito de elementos, o $\wedge$ de todos eles é diferente de $0$), deve existir um homomorfismo $u: \mathcal{B} \rightarrow \{0,1\}$ tal que $u|_{T} = 1$. 
\end{itemize}

\end{frame}

\begin{frame}{}
\frametitle{Semântica - completude da lógica de primeira ordem}
\pause

\begin{itemize}
\item Em lógica de primeira ordem, a semântica é dada por modelos, que são conjuntos $M$ onde interpretamos os símbolos de funções, relações e constantes como funções, relações e constantes de verdade. \pause

\item Também temos aqui completude, chamado também de Teorema da Completude de Gödel: se um conjunto de fórmulas $T$ não prova a contradição, então existe um modelo que satisfaz $T$. \pause

\item A reformulação algébrica desse resultado é ainda mais algebricamente elegante do que no cálculo proposicional: Toda álgebra de Halmos é semisimples. \pause
\item  Pra uma estrutura algébrica $A$ 'qualquer', a estrutura é dita simples se ela não admite quocientes não-triviais (equivalentemente, todo homomorfismo partindo de $A$ é injetivo ou constante). \pause
\item Já $A$ é dito semisimples se, pra todo $a \in A$ tal que $a \neq 0$ então existe um homomorfismo $f: A \rightarrow S$ em uma estrutura algébrica simples $S$ onde $f(a) \neq 0$.
\end{itemize}
\end{frame}
